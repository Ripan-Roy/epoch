# Epoch v0.1.0-alpha.3

Epoch's third source prerelease joins the typed fixed-voter profile slices into
one regional multi-tablet runtime and gives the Go managed-control bridge
transactional process-crash durability. It is an experimental alpha for
evaluation and development, not a production release.

## Source preview only

GitHub provides ZIP and tar.gz archives of the tagged source tree. Those source
archives are the only release downloads. This release publishes no binaries,
container images, installers, SDK packages, or package-registry artifacts.

No open-source or commercial license has been selected. This prerelease grants
no permissions beyond rights already provided by applicable law and GitHub's
Terms of Service and must not be described as an open-source release.

## Highlights

- A dedicated three-voter Rust catalog group now owns fully qualified resource
  identity, monotonic generations, stable tablet/group allocation, canonical
  idempotent commands, and delete/recreate tombstones.
- One bounded Rust node process supervises the catalog plus simultaneous Cache,
  Stream, Queue, and Event Bus tablet groups behind resource/shard routing.
  Resource generation and tablet epoch fence every experimental data request.
- The Go `RegionalAdminService` reconciles desired resources through multiple
  Rust authority endpoints and exposes only actually observed voters and
  leaders through the exact-origin browser BFF.
- Go desired resources, observed status, request-token outcomes, and generation
  tombstones commit transactionally to a versioned single-owner bbolt database
  before acknowledgement. Corruption, unknown schemas, and concurrent
  ownership fail startup closed.
- The TypeScript console distinguishes pending, ready, degraded, and failed
  placement without treating desired replicas as achieved topology or claiming
  zone/rack separation.
- Real-process and three-container campaigns cover Go control `SIGKILL` and
  same-file exact replay, catalog and four-profile leader replacement, truthful
  degradation, catch-up, all-voter `SIGKILL`, same-volume reopen, and digest
  convergence.
- The published documentation includes the regional ownership/recovery model
  and exact executable Go, Java, and Python standalone durability quickstarts.

## Build and try it from source

The pinned baseline is Rust 1.97.1, Go 1.26.5, protoc 35.1, Buf 1.72.0, Python
3.11+, Java 25+, Node.js 24.18.0, pnpm 10.28.0, and Docker Compose v2.

```shell
git clone https://github.com/Ripan-Roy/epoch.git
cd epoch
git checkout v0.1.0-alpha.3
pnpm install --frozen-lockfile
make check
```

Start the standalone node:

```shell
cargo run -p epoch-node -- --data-dir .epoch
```

For the experimental regional runtime, follow the
[regional guide](../REGIONAL_RUNTIME.md). The Go control metadata file defaults
to `data/control/registry.db` and can be selected with
`EPOCH_CONTROL_STATE_PATH`.

## Compatibility and upgrade notes

APIs, protocols, Rust EPRS/catalog formats, the Go bbolt schema, SDKs, module
paths, and compatibility claims remain provisional and may change without
migration support. Existing valid standalone journals retain their documented
reopen behavior.

Alpha.2 kept Go desired state only in process memory, so there is no durable Go
registry to migrate. Alpha.3 creates its version-one database on first control
startup. Operators evaluating an existing regional catalog must review and
reapply desired resources deliberately; automatic import from Rust catalog
state is not provided.

## Alpha limitations

- Regional placement is exactly three configured voters, not a zone/rack-aware
  solver. Dynamic membership, online rebalance, repair, split/merge, snapshots,
  compaction, retention deletion, and read barriers remain incomplete.
- Rust regional HTTP, Go management, and console surfaces are experimental,
  unauthenticated, and lack TLS.
- Go metadata durability is one-process and one-file. It is not replicated,
  multi-instance linearizable, automatically backed up, or protected by
  management leader election.
- Typed regional routes have no stable public SDK contract. Go, Java, and
  Python SDKs cover the standalone HTTP profiles only.
- The Event Bus owns replicated delivery intent and attempt state but has no
  built-in pull, push, webhook, Queue, Stream, or HTTP target executor.
- No Cargo crate, `epoch.local/epoch` Go module, `io.epoch:epoch-sdk` Maven
  artifact, `epoch-sdk` Python distribution, npm package, OCI image, installer,
  signed binary, SBOM, or provenance statement is released from this tag.
