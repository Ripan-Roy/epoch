# Epoch v0.1.0-alpha.4

Epoch's fourth source prerelease turns the regional fixed-voter prototype into
an authenticated, multi-profile SDK slice with bounded recovery automation,
multi-shard Stream consumption, and leader-owned signed webhook delivery. It is
an experimental alpha for evaluation and development, not a production
release.

## Source preview only

GitHub provides ZIP and tar.gz archives of the tagged source tree. Those source
archives are the only release downloads. This release publishes no binaries,
container images, installers, SDK packages, or package-registry artifacts.

No open-source or commercial license has been selected. This prerelease grants
no permissions beyond rights already provided by applicable law and GitHub's
Terms of Service and must not be described as an open-source release.

## Highlights

- Authenticated regional Stream, Queue, Cache, and Event Bus v1 routes now use
  one deny-by-default Go/Rust bootstrap policy, exact tenant scopes,
  generation/tablet/term fencing, leader-only writes, quorum-confirmed
  linearizable reads, and bounded credential-free audit decisions.
- Repository-local Go, Java, and Python clients cover the implemented regional
  lifecycle of all four profiles with matching discovery, authorization,
  idempotency, typed validation, and one bounded routing rediscovery contract.
- Stream resources materialize independently replicated shards with a pinned
  UTF-8 FNV-1a routing contract, atomic caller-framed batches, time/size/count
  retention, replicated consumer checkpoints, coordinated membership, and
  session-fenced fetch/commit. Real Python recovery crosses leader loss, voter
  catch-up, and all-node same-volume reopen.
- Compatible native checkpoints now capture every profile, retain bounded
  exact-retry evidence, physically reclaim obsolete EPRS generations, catch up
  lagging voters, and run automatically on every regional voter after a
  configurable applied-index threshold.
- Current regional leaders automatically propose due Stream, Queue, Cache, and
  Event Bus maintenance commands. Authorized topology reports the scheduler
  and checkpoint boundaries without treating process-local counters as
  replicated metrics.
- The Event Bus can execute signed HTTP/webhook targets only after committing
  and awaiting an exact delivery lease. HMAC-SHA-256 signatures, CloudEvents
  1.0 binary-mode headers, retry/rejection classification, public-address HTTPS
  enforcement, DNS pinning, redirect/proxy suppression, lease-capped I/O, and
  external key rotation are covered by deterministic and real-process tests.
- Go, Java, and Python include exact-body webhook verification helpers with one
  shared signature vector and return the `(delivery ID, attempt)` identity that
  receivers must store durably for replay defense.
- The GitHub Pages documentation was rebuilt as a searchable, responsive
  Mintlify/Vercel-inspired reference with persistent language selection,
  syntax-highlighted source, end-to-end regional SDK guides, recovery evidence,
  and the complete signed-webhook operator and receiver contract.

## Build and try it from source

The pinned baseline is Rust 1.97.1, Go 1.26.5, protoc 35.1, Buf 1.72.0, Python
3.11+, Java 25+, Node.js 24.18.0, pnpm 10.28.0, and Docker Compose v2.

```shell
git clone https://github.com/Ripan-Roy/epoch.git
cd epoch
git checkout v0.1.0-alpha.4
pnpm install --frozen-lockfile
make check
```

Start the standalone node:

```shell
cargo run -p epoch-node -- --data-dir .epoch
```

For the experimental regional runtime, policy fixtures, signing-key setup, and
three-language SDK examples, follow the
[regional guide](../REGIONAL_RUNTIME.md) and the
[Event Bus SDK guide](../REGIONAL_EVENT_BUS_SDK.md).

## Compatibility and upgrade notes

- Regional management and data endpoints now fail closed without a matching
  bootstrap bearer policy. Alpha.3 evaluation deployments must configure
  `EPOCH_AUTH_POLICY_PATH`, the Go-to-Rust regional credential, and client
  bearer credentials before using the regional surface.
- EPRS records, profile snapshots, and Stream/Event Bus commands added in this
  release are versioned and retain tested reads of valid alpha.3 histories.
  Alpha.3 binaries do not understand every alpha.4 record, so downgrade after
  writing alpha.4 state is not supported.
- Existing standalone journals retain their documented reopen behavior. The Go
  control registry remains a version-one, single-owner bbolt database; this
  release does not add automatic import, backup, or multi-instance ownership.
- Regional SDK APIs remain source-only and provisional. Callers should expect
  method and wire changes before a stable release and must not infer registry
  availability from the checked-in package metadata.
- Signed webhook receivers must verify the exact raw body, enforce an
  application-appropriate timestamp window, and atomically persist the
  `(delivery ID, attempt)` replay identity before accepting a side effect.

## Alpha limitations

- Regional placement is exactly three configured voters. Dynamic membership,
  rack-aware placement, online transfer/rebalance, automatic repair, and
  production failover SLOs are not implemented.
- Bootstrap credentials are long-lived development secrets. OIDC, expiry and
  revocation, TLS/mTLS peer identity, replicated policy, at-rest encryption,
  immutable audit export, and production secret delivery remain open.
- Signed webhook execution is at-least-once and public-HTTPS-only outside the
  explicit loopback development mode. A managed egress proxy, receiver replay
  store, secret-manager hot reload, penetration report, rate limiting, and
  Queue/Stream target executors are not included.
- Stream and Queue consumption remain HTTP request/response alpha slices rather
  than stable bidirectional protocols. Cooperative revoke, atomic
  assignment-plus-offset/output transactions, online shard expansion,
  follower routing, and production scale evidence remain open.
- Checkpoints are internal fixed-voter recovery images, not downloadable
  backups or point-in-time recovery. No scheduled restore drill, artifact
  catalog, encryption, legal hold, or cross-region disaster recovery is
  claimed.
- No Cargo crate, public Go module, Maven artifact, Python distribution, npm
  package, OCI image, installer, signed binary, SBOM, or provenance statement
  is released from this tag.
