# Epoch v0.1.0-alpha.5

Epoch's fifth source prerelease delivers three complete vertical capabilities:
leader-owned Event Bus delivery to Epoch-native targets, deterministic managed
Cache eviction and atomic access batches, and replicated resource governance
with authorized cost-driver attribution. It remains an experimental alpha for
evaluation and development, not a production release.

## Source preview only

GitHub provides ZIP and tar.gz archives of the tagged source tree. Those source
archives are the only release downloads. This release publishes no binaries,
container images, installers, SDK packages, or package-registry artifacts.

No open-source or commercial license has been selected. This prerelease grants
no permissions beyond rights already provided by applicable law and GitHub's
Terms of Service and must not be described as an open-source release.

## Highlights

- Newly managed regional resources require canonical owner, cost center,
  classification, and bounded custom tags. Go durably records governance and
  Rust catalog command/snapshot v3 replicates it without breaking reads of valid
  legacy state.
- gRPC, HTTP, and the browser console filter authorized inventory with exact AND
  matching over governance fields. Deterministic resource/shard attribution is
  grouped by cost center and classification after tenant authorization; it does
  not claim usage metering, rates, currency, invoices, or billing.
- The complete governance value survives the real Go control-process `SIGKILL`,
  Rust catalog replication, leader replacement, voter catch-up, and all-node
  same-volume recovery campaign.
- Managed Cache configuration now reaches every voter. No-eviction plus
  deterministic all-key/volatile LRU, LFU, random, and TTL policy decisions are
  replayable, capacity admission is atomic, and eviction receipts use canonical
  victim ordering.
- Cache `Get` is a committed access transition for LRU/LFU accounting while
  `Observe` remains pure. Go, Java, and Python expose the existing bounded
  same-shard transaction as an atomic batch with one correlated result per
  operation.
- Event Bus workers deliver to generation-pinned Epoch Queue and keyed
  multi-shard Stream targets. Stable target idempotency and
  committed-target-before-source-Ack ordering prevent duplicate insertion in
  the pinned target incarnation without claiming a cross-tablet transaction.
- GitHub Pages includes the complete Go/Java/Python regional SDK guides, Cache
  eviction/access/batch guide, Queue/Stream target guide, and a dedicated
  resource-governance page.

## Build and try it from source

The pinned baseline is Rust 1.97.1, Go 1.26.5, protoc 35.1, Buf 1.72.0, Python
3.11+, Java 25+, Node.js 24.18.0, pnpm 10.28.0, and Docker Compose v2.

```shell
git clone https://github.com/Ripan-Roy/epoch.git
cd epoch
git checkout v0.1.0-alpha.5
pnpm install --frozen-lockfile
make check
```

For the regional runtime and governed-resource creation, follow
[Resource Governance](../RESOURCE_GOVERNANCE.md) and
[Regional Runtime](../REGIONAL_RUNTIME.md). The public documentation contains
the exact repository-local Go, Java, and Python SDK examples.

## Compatibility and upgrade notes

- New resources entering through the Go managed regional API must include the
  complete governance object. Valid legacy bbolt and Rust catalog resources
  without governance remain readable and recoverable.
- Rust catalog command and snapshot v3 are additive. This release reads valid
  legacy v1/v2 bytes; older binaries do not understand v3 governance state, so
  downgrade after committing governed resources is not supported.
- Cache command/snapshot extensions preserve tested historical reads. Older
  binaries do not understand every new access record and must not be used for a
  live downgrade after alpha.5 state has been written.
- SDK APIs remain repository-local, source-only, and provisional. Package
  publication is intentionally deferred.

## Alpha limitations

- Governance metadata is not yet an ABAC enforcement input. Organization
  policy, immutable audit export, payload redaction, residency, legal hold,
  recoverable deletion, usage meters, rates, invoices, and billing remain open.
- Regional placement is exactly three configured voters. Dynamic membership,
  rack-aware placement, online transfer/rebalance, automatic repair, and
  production failover SLOs are not implemented.
- Bootstrap credentials are long-lived development secrets. OIDC, expiry and
  revocation, TLS/mTLS peer identity, encryption, replicated policy, and
  production secret delivery remain open.
- Queue/Stream Event Bus delivery is at-least-once and not an atomic
  source-and-target transaction. Unsigned/custom target execution, rate
  limiting, broader executor crash matrices, and external audit remain open.
- Cache still lacks byte-pressure accounting, native multiplexing/automatic
  coalescing, exportable backup/PITR, Pub/Sub, change streams, advanced indexes,
  and production scale/SLO evidence.
- No Cargo crate, public Go module, Maven artifact, Python distribution, npm
  package, OCI image, installer, signed binary, SBOM, or provenance statement
  is released from this tag.
