# Epoch v0.1.0-alpha.6

Epoch's sixth source prerelease completes the alpha implementation contract for
every non-deferred Cache and State requirement (`CACHE-001` through
`CACHE-014`). It is a fixed-topology, single-shard engineering alpha for
evaluation and development, not a production service or performance claim.

## Source preview and license

The repository source is available under the MIT License. GitHub provides ZIP
and tar.gz archives of the tagged tree; those source archives are the only
release downloads. This release publishes no binaries, container images,
installers, SDK packages, or package-registry artifacts.

## Highlights

- Deterministic admission now enforces entry count plus separate canonical
  memory and cold byte caps across no-eviction and all-key/volatile LRU, LFU,
  random, and TTL policies. Requested and achieved `replicated_memory` or
  `quorum_durable` modes are reported explicitly.
- Typed state-machine transforms cover hash/list/set/sorted-set mutation,
  bitmaps, HLL-like cardinality, Bloom/Cuckoo filters, microdegree geo, bounded
  JSON documents and exact secondary indexes, and bounded exact vector/text
  hybrid search with metadata filters.
- A replicated 1,024-record change cursor includes mutations, expiry, eviction,
  and restore. Canonical checksummed Cache backups expose their restorable
  revision window; one consensus command performs point-in-time restore with
  configuration/capacity validation and fresh non-ABA versions.
- Atomic batches remain all-or-nothing. Native multiplexing carries up to 128
  independently committed identities in one request and returns request-ordered
  correlated outcomes with `atomic: false`.
- Cache Pub/Sub adds exact-channel and wildcard subscriptions with explicit
  node affinity, no persistence, drain-on-poll, bounded queues, drop counters,
  and at-most-once delivery.
- Every regional voter fsyncs cold-class values to a canonical local-file read
  path, removes stale files after committed deletion/eviction/restore, rebuilds
  the directory on recovery, and integrity-checks reads. Status publishes
  observed local-file microseconds as not an SLO. Canonical state still remains
  in the tablet image; this is not heap offload.
- Go, Java, and Python expose the complete lifecycle. The public docs compile
  exact examples for cold values, backup/PITR, advanced query, multiplex,
  Pub/Sub, changes, locks, TTL, and ordinary atomic state operations.
- The repository now includes an MIT `LICENSE` and a contributor guide. External
  contributions are deliberately small and issue-scoped; cross-stack feature
  releases remain maintainer-coordinated.

## Compatibility and upgrade notes

- Cache snapshot v4 adds advanced values, storage classes/byte accounting,
  change history, and PITR state. Readers continue to accept v1 through v3.
- Historical command bytes remain readable; additive transform and restore
  commands require alpha.6. Do not downgrade a live tablet after alpha.6-only
  state has committed.
- Backup restore requires matching immutable Cache configuration and a target
  revision inside the artifact's published window. Corrupt, non-canonical,
  oversized, mismatched, or out-of-window artifacts reject atomically.
- Go, Java, and Python APIs remain repository-local and provisional. Package
  publication is intentionally deferred.

## Alpha limitations

- Regional Cache is one logical shard on exactly three configured voters.
  Dynamic membership, rack-aware placement, online split/rebalance/repair,
  follower-served linearizable reads, and production failover SLOs are open.
- The cold path is an fsynced local read tier backed by replicated canonical
  state; it does not offload the tablet heap or prove flash capacity/latency at
  production scale.
- Cache backup/PITR is caller-managed and resource-local. Managed schedules,
  encryption/key management, remote catalogs/retention, cross-resource restore,
  and all-cluster disaster recovery remain open.
- Pub/Sub is deliberately lossy and node-local. It is not replayable,
  acknowledged, or resilient to disconnect, rerouting, or process loss.
- Automatic client coalescing, RESP compatibility, CRDTs, generated response
  models, production identity/TLS/mTLS, performance/soak evidence, and public
  package artifacts remain open.
- No Cargo crate, public Go module, Maven artifact, Python distribution, npm
  package, OCI image, installer, signed binary, SBOM, or provenance statement
  is released from this tag.
