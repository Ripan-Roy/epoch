# Epoch v0.1.0-alpha.10

Epoch's tenth source prerelease closes the product/runtime development train
with automatic HTTP source ingestion, a real Kubernetes operator, a typed
management CLI, source-built deployment images, CI gates, and end-to-end
operations documentation. It remains a fixed-voter engineering alpha; the
next release train is exclusively beta hardening.

## Source preview and license

The repository source is available under the MIT License. GitHub provides ZIP
and tar.gz archives of the tagged tree; those source archives are the only
release downloads. This release publishes no prebuilt binaries, container
images, installers, SDK packages, or package-registry artifacts.

## Highlights

- The active Event Bus leader polls bounded generic HTTP/CloudEvents source
  connectors through the existing public-address-only, DNS-pinned,
  allowlisted, no-proxy/no-redirect egress boundary.
- Every source record has a stable connector/batch/index proposal identity.
  Applied or error-routed results commit before the replicated cursor advances,
  making crash-before-checkpoint replay duplicate-safe inside the Bus.
- A controller-runtime `EpochCluster` operator reconciles the supported exact
  three-voter data plane, one durable control owner, stable peer/public/control
  Services, PVCs, explicit placement identity, required voter anti-affinity,
  hardened pod security, policy/credential references, and status conditions.
- Operator reconciliation fails closed before workload creation when required
  policy or credential data is absent. API-server defaults do not cause update
  churn, while drift in operator-owned fields is repaired.
- The generated-contract Go `epoch` CLI provides strict JSON/YAML apply,
  fully-qualified get/list/delete, automatic retry identities, optimistic
  delete fencing, stable protobuf JSON, and HTTP plus authenticated-gRPC
  diagnostics.
- Separate node, control, and operator Dockerfiles plus the CRD, RBAC,
  leader-elected Deployment, sample custom resource, Kustomize validation, and
  CI image builds form the source installation package.
- Public documentation now contains executable source connector, CLI, and
  Kubernetes lifecycle guides with exact failure ordering and explicit alpha
  non-claims.

## Compatibility and upgrade notes

- No persisted Bus command or snapshot version is replaced. Source polling
  uses existing additive connector, record-result, batch, and checkpoint
  integration operations and stable proposal lookup.
- The Kubernetes API is `platform.epoch.dev/v1alpha1`; it is provisional and
  currently supports exactly three data replicas.
- Do not perform an unattended image upgrade. There is no mixed-version
  compatibility contract, one-voter-at-a-time coordinator, or automatic
  rollback yet.
- Go, Java, and Python SDK APIs remain repository-local and provisional.
  Package-manager publication remains intentionally deferred.

## Alpha limitations and beta gates

- Control, data, and CLI transports are plaintext and token-authenticated.
  TLS/mTLS, short-lived identity, certificate rotation, and OIDC are required
  before beta.
- Consensus membership remains three fixed voters. There is no automatic
  replacement, online rebalance, or general topology solver.
- Internal voter checkpoints are not downloadable backups. Scheduled backup,
  encrypted cataloging, restore validation, semantic PITR, and guarded rolling
  upgrades remain open.
- Generic HTTP/CloudEvents is the only automatic source adapter. PostgreSQL/
  MySQL CDC, Kafka, object storage, private egress, and connector certification
  remain open.
- Production load, soak, latency, failover-SLO, protocol-conformance, abuse,
  and live-Kubernetes recovery reports are not claimed by this release.
- No Cargo crate, public Go module, Maven artifact, Python distribution, npm
  package, OCI image, installer, signed binary, SBOM, or provenance statement
  is released from this tag.
