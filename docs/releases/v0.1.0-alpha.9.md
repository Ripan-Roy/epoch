# Epoch v0.1.0-alpha.9

Epoch's ninth source prerelease completes the native Event Bus and integration
development surface across `BUS-001`–`BUS-015`. It adds bounded replicated
integration state, rate/retention/redrive and long poll, leader-owned managed
targets, and matching Go, Java, Python, runtime, console, and public docs. This
remains a fixed-voter engineering alpha, not a production scale, protocol-
compatibility, or security-certification claim.

## Source preview and license

The repository source is available under the MIT License. GitHub provides ZIP
and tar.gz archives of the tagged tree; those source archives are the only
release downloads. This release publishes no binaries, container images,
installers, SDK packages, or package-registry artifacts.

## Highlights

- Event Bus delivery now includes committed per-subscription rate/burst,
  bounded long poll, terminal dead-letter retention and exact redrive, plus
  count/age archive retention with leader-owned maintenance.
- Declarative routing adds bounded rename, constants, templates, operation/
  value/output limits, and deterministic no-network lookup enrichment.
- One replicated integration image owns Avro/JSON Schema/Protobuf definitions,
  compatibility revisions, validation policies, MQTT sessions/retained/QoS/
  shared cursors, event catalog, endpoint health, function resources, and
  connector lifecycle/checkpoints/replay/partial errors/secret versions.
- Integration mutations reject atomically beyond 2 MiB. Every successful Bus
  tablet mutation must remain snapshot-encodable, and restore revalidates
  semantic identities, revisions, references, receipts, checkpoints, MQTT
  state, URLs, canonical bytes, and digests.
- A source-leader worker executes API destinations, deterministic endpoint
  pools, functions, and target/bidirectional connectors. It leases before I/O,
  emits binary or structured CloudEvents, sends stable idempotency metadata,
  supports API-key/OAuth client credentials for API destinations and optional
  bearer credentials for function/connector calls, and commits endpoint failure
  or connector checkpoint state before failover/source settlement.
- Public-only DNS validation/address pinning, exact host allowlists, disabled
  redirects and ambient proxies, lease-capped timeouts, bounded/redacted secret
  files, OAuth response bounds, and token caching are covered by focused tests
  including a real loopback OAuth and target receiver.
- Go, Java, and Python expose matching target/auth/transform/rate models,
  delivery redrive/archive maintenance, 30-second long poll, generic strict
  integration operations, and linearizable integration-state reads. The Pages
  guide documents the full end-to-end surface and explicit non-claims.

## Compatibility and upgrade notes

- Legacy Event Bus command v1/v2/v3 and snapshot images remain readable when
  their newer state is absent. Integration operations use additive command v4;
  rate/retention/redrive and managed metadata use command v5.
- Event Bus snapshot v4 carries integration state and v5 carries archive
  retention. Valid older images recover with empty/default newer state.
- The recovery digest selects its historical domain when integration/archive-
  retention state is absent, preserving legacy golden bytes.
- Do not downgrade a live Bus after integration, rate/retention/redrive, or
  managed-target metadata has committed.
- Go, Java, and Python APIs remain repository-local and provisional. Package
  publication is intentionally deferred.

## Alpha limitations

- One Event Bus resource is one logical shard. Pull/long poll is request/
  response; there is no bidirectional streaming push or dispatcher coordinator.
- MQTT semantic state is replicated, but there is no MQTT 5 wire gateway or
  protocol-conformance claim. Schema validation is Epoch's bounded structural
  field model, not every official Avro/JSON Schema/Protobuf compiler.
- Target/bidirectional connectors execute; automatic external source polling,
  marketplace/certification, and active endpoint-health restoration remain
  open.
- Managed secrets use a strict startup file. There is no hot reload, external
  secret-manager identity, private-network egress, or network-level egress
  proxy. The worker is not yet isolated in a separate OS sandbox.
- Unsigned legacy HTTP/webhook intent remains application-dispatched. External
  side effects are at least once and require receiver idempotency; Epoch does
  not claim a distributed transaction or exactly-once arbitrary side effect.
- Production identity/TLS/OIDC/mTLS, formal review/fuzzing, load/soak/scale
  evidence, generated response/integration models, multi-shard routing,
  backups/PITR, and the exhaustive fault matrix remain release gates.
- No Cargo crate, public Go module, Maven artifact, Python distribution, npm
  package, OCI image, installer, signed binary, SBOM, or provenance statement
  is released from this tag.
