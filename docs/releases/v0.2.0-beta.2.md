# Epoch v0.2.0-beta.2

Epoch's first publishable beta closes the alpha operational boundary as one
vertical feature: secure managed transport, portable encrypted recovery,
learner-first membership changes, guarded Kubernetes upgrades, production
source-adapter foundations, signed fault evidence, and verifiable OCI images.

Beta means the complete native Epoch surface can be installed and exercised end
to end in an existing Kubernetes development or evaluation environment. It does
not mean GA compatibility, a hosted-service SLO, or unattended production
certification.

## Release correction

The immutable `v0.2.0-beta.1` tag passed source, exact-main, Pages, Kubernetes,
connector, and amd64 image validation, but its release workflow aborted in the
arm64 node build when `protobuf-build` selected a faulty vendored `protoc`
fallback. No GitHub prerelease was created. Beta.2 uses an explicit
target-native Protobuf compiler and adds a protected native-arm64 node-image
gate so this failure is caught before publication.

## Published artifacts

The tag workflow publishes these exact multi-platform OCI manifests for
`linux/amd64` and `linux/arm64`:

- `ghcr.io/ripan-roy/epoch-node:v0.2.0-beta.2`
- `ghcr.io/ripan-roy/epoch-control:v0.2.0-beta.2`
- `ghcr.io/ripan-roy/epoch-operator:v0.2.0-beta.2`
- `ghcr.io/ripan-roy/epoch-cli:v0.2.0-beta.2`

Every manifest is built from the exact current `main` tag, inspected as
non-root, signed keylessly with Sigstore, and accompanied by GitHub build
provenance plus separate SPDX SBOM attestations and downloadable SBOM assets for
each platform. Epoch does not publish `latest`. Package-manager SDKs, raw binary
archives, OS installers, and Helm charts remain intentionally deferred.

## Highlights

- TLS protects public HTTP and gRPC; mTLS protects peer and control-to-data
  traffic. Go, Java, Python, and the CLI support custom trust roots and optional
  client identity.
- Versioned regional backups authenticate checksums and identities, encrypt
  semantic state with AES-256-GCM, and restore only into a validated fresh
  destination. The operator schedules non-overlapping backups and records
  bounded receipts.
- Catalog and Raft persist three- or five-voter membership. Replacement admits
  a learner, refreshes membership-bearing snapshots, waits for catch-up, uses
  joint consensus, and removes the old voter.
- Image changes require a fresh backup and run through serialized
  preflight/drain/update/postflight states.
- Event Bus source ingestion shares one leader-owned, bounded contract across
  HTTP/CloudEvents, S3-compatible/Azure/GCS objects, PostgreSQL logical
  replication, MySQL row binlogs, and Kafka consumer groups.
- A signed resumable fault runner binds source, image, platform, plans, logs,
  and results into independently verifiable evidence. Sequential leader faults
  now require exact per-group recovery barriers, with bounded diagnostics for
  every voter's applied count and state digest.
- A clean one-control/four-worker Kind lifecycle proves mTLS install,
  all-profile traffic, encrypted backup, compacted-log voter replacement,
  backup-gated rollout, fresh-cluster restore, digest equality, and continued
  writes.

## Install and try

Resolve and verify immutable digests before use; do not deploy a tag alone as
the final trust decision.

```shell
git clone https://github.com/Ripan-Roy/epoch.git
cd epoch
git checkout v0.2.0-beta.2
make bootstrap-check
make check
make kubernetes-config
```

Then follow the Kubernetes, CLI, and end-to-end Go, Java, and Python SDK guides
on the published documentation site.

## Beta limitations

- No RESP3, Kafka broker, AMQP, or MQTT compatibility gateway is claimed.
- No multi-region promotion/failback, arbitrary voter count, automatic general
  rebalance, or cloud workload-identity certification is included.
- Production CSI behavior, genuinely mixed-version compatibility, measured
  RPO/RTO, cross-zone failure, and the required 30-day operating campaign remain
  separate gates.
- SDK APIs remain provisional and repository-local. Package-manager publication
  is deferred; applications should pin this exact release.
