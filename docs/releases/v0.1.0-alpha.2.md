# Epoch v0.1.0-alpha.2

Epoch's second source prerelease advances the four workload profiles from
standalone foundations to deterministic, typed fixed-voter replication slices.
It is an experimental alpha for evaluation and development, not a production
release.

## Source preview only

GitHub provides ZIP and tar.gz archives of the tagged source tree. Those source
archives are the only release downloads. This release publishes no binaries,
container images, installers, SDK packages, or package-registry artifacts.

No open-source or commercial license has been selected. This prerelease grants
no permissions beyond rights already provided by applicable law and GitHub's
Terms of Service and must not be described as an open-source release.

## Highlights

- Typed Stream, Queue, Cache, and Event Bus tablets now apply canonical
  commands only after fixed-three-voter majority persistence and recover from
  the complete EPRS proposal history.
- The Queue tablet covers acquisition leases, renewal, acknowledgement,
  release, Nack, reject, deterministic retry and jitter, DLQ history, redrive,
  failover fencing, and all-voter restart recovery.
- The Cache tablet covers strict values, atomic batches, revisions, CAS,
  optimistic transactions, increment, deterministic TTL maintenance, and
  entry-term-fenced renewable locks.
- The Event Bus tablet covers topics and subscriptions, wildcard and JSON
  filters, transformations, bounded archive/replay, atomic per-subscription
  delivery intent, leases, dispatcher fencing, retry timing, timeout
  maintenance, acknowledgement, and dead-letter terminal state.
- Real-process and three-container tests cover minority non-commit, leader
  replacement, catch-up, exact retry, semantic conflicts, convergence, and
  one-voter plus all-voter `SIGKILL`/same-path reopen.
- The documentation site has a redesigned Mintlify/Vercel-inspired experience
  with exact executable Go, Java, and Python seed, crash, restart, and
  verification quickstarts.
- Release metadata is now synchronized across Rust, Go, Java, Python, and
  TypeScript and tags are accepted only at the current `main` commit.

## Build and try it from source

The pinned baseline is Rust 1.97.1, Go 1.26.5, protoc 35.1, Buf 1.72.0, Python
3.11+, Java 25+, Node.js 24.18.0, pnpm 10.28.0, and Docker Compose v2.

```shell
git clone https://github.com/Ripan-Roy/epoch.git
cd epoch
git checkout v0.1.0-alpha.2
pnpm install --frozen-lockfile
make check
```

Start the standalone node:

```shell
cargo run -p epoch-node -- --data-dir .epoch
```

## Compatibility and upgrade notes

APIs, protocols, storage formats, SDKs, module paths, and compatibility claims
remain provisional and may change without migration support. Existing valid
standalone journals retain their documented reopen behavior, but this release
does not promise general alpha-to-alpha format migration or rollback.

## Alpha limitations

- The replicated profiles are mutually exclusive modes for one statically
  configured three-voter group, not simultaneous public multi-tablet or
  placement-aware quorum durability.
- Replica transport is bounded but unauthenticated plaintext HTTP. Dynamic
  membership, placement, snapshots, compaction, read barriers, repair, and
  exhaustive model/chaos evidence remain incomplete.
- The Event Bus owns replicated delivery intent and attempt state but has no
  built-in pull, push, webhook, Queue, Stream, or HTTP target executor.
- Production authentication, authorization, TLS/mTLS, encryption, KMS,
  tenancy, quotas, immutable audit, signed webhook delivery, and managed
  operations are not implemented.
- No Cargo crate, `epoch.local/epoch` Go module, `io.epoch:epoch-sdk` Maven
  artifact, `epoch-sdk` Python distribution, npm package, OCI image, installer,
  signed binary, SBOM, or provenance statement is released from this tag.
