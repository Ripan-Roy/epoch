# Epoch v0.1.0-alpha.7

Epoch's seventh source prerelease completes the development implementation for
the advanced Stream requirements (`STREAM-007` through `STREAM-015`). It adds a
bounded, replicated state-services layer to each Stream tablet and exposes the
same end-to-end lifecycle through Go, Java, Python, HTTP, and the documentation
site. This remains a fixed-voter engineering alpha, not a production
performance or availability claim.

## Source preview and license

The repository source is available under the MIT License. GitHub provides ZIP
and tar.gz archives of the tagged tree; those source archives are the only
release downloads. This release publishes no binaries, container images,
installers, SDK packages, or package-registry artifacts.

## Highlights

- Replicated producer epochs and contiguous sequences provide fencing,
  conflict detection, and bounded exact retry history.
- Tablet-local transactions atomically expose up to 128 records and one
  colocated consumer offset. Read-committed hides pending and aborted records;
  read-uncommitted exposes pending history for diagnostics.
- Committed state-dependent failures are typed `rejected` outcomes. They leave
  staged state unchanged, replay exactly, survive snapshots, and do not
  fail-stop a healthy tablet.
- Key compaction retains the latest committed keyed value, preserves unkeyed
  records, removes aborted/superseded history, and expires JSON-null tombstones
  at an inclusive deadline.
- Immutable historical objects retain canonical bytes, exact covered ranges,
  and SHA-256 checksums. Reads verify and merge tiered and hot history while
  preserving transaction isolation.
- Manual and leader-scheduled captures produce canonical JSON Lines or JSON
  arrays with durable offset/deadline checkpoints, pending-transaction
  barriers, missed-deadline catch-up, and bounded artifact rotation.
- Pull, shared push long poll, and consumer-identified dedicated long poll are
  available through all three SDKs. Dedicated mode is scheduling isolation,
  not a bandwidth reservation.
- Cross-cluster ingress atomically records contiguous source checkpoints,
  source-to-local offset mappings, loop paths, and local records. Partition
  advice supplies an expand-only target.
- Go, Java, and Python can merge 1–128 named Stream members deterministically
  as a logical superstream while explicitly reporting that member snapshots are
  independently linearizable rather than globally atomic.

## Compatibility and upgrade notes

- Canonical Stream command v7 is additive. Command v1 through v6 bytes remain
  readable.
- Stream log snapshot v2 preserves sparse offsets introduced by compaction and
  accepts v1 images. Stream tablet snapshot v4 adds state services and accepts
  v1 through v3 images with empty advanced state.
- State-services snapshot v2 adds capture schedules and accepts v1 snapshots
  with no configured schedules.
- Do not downgrade a live tablet after command-v7 state has committed or after
  a v2 sparse Stream snapshot has been installed.
- Go, Java, and Python APIs remain repository-local and provisional. Package
  publication is intentionally deferred.

## Alpha limitations

- Transactions and atomic offset commits are one-tablet operations. There is no
  cross-shard, external-database, or sink transaction coordinator.
- Tier and capture bytes remain embedded in replicated tablet state. External
  cloud-object mirroring/offload, outage drills, and latency SLO evidence are
  separate production gates.
- Replication in this release is the deterministic ingress/checkpoint primitive;
  deployment-specific inter-region workers and two-region RPO/RTO drills remain
  open.
- Dedicated consumers have a separate notification lane but no reserved
  throughput or published isolation SLO. Persistent bidirectional streaming is
  not implemented.
- Dynamic membership, placement-domain enforcement, production identity,
  TLS/OIDC/mTLS, generated response models, security audit, fuzz/soak/scale
  evidence, and the production fault matrix remain open.
- No Cargo crate, public Go module, Maven artifact, Python distribution, npm
  package, OCI image, installer, signed binary, SBOM, or provenance statement
  is released from this tag.
